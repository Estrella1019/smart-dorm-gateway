# 框架验证记录

验证时间：2026 年 10 月 27 日。环境：macOS、Python 3.14.2。

执行命令：`python3 -m unittest discover -s tests -v`。

结果：17 项测试全部通过。网络测试实际监听 `127.0.0.1` 的随机空闲 TCP 端口，并连接模拟设备与客户端；不是仅验证模拟函数返回值。

覆盖范围：

- TOML 样例加载与非法配置拒绝。
- TCP 拆分头与消息体、连续多帧、超长帧、半帧断开、非法 JSON。
- 模拟灯注册、开灯、关灯以及更新后的设备查询。
- 设备不存在、确认超时、控制期间断线、待确认记录清理。
- 重复在线编号、同设备并发指令拒绝、跨设备伪确认隔离。
- 异常连接与非法注册不影响后续服务，首消息超时。

本地运行环境限制绑定端口时，需要允许测试进行本机网络监听；协议和配置测试本身不需要端口。测试退出后关闭其创建的服务与连接。

尚未验证 Windows/Linux 实机、其他 Python 版本、跨电脑局域网、性能上限与远端 GitHub Actions。CI 文件已配置 Python 3.11—3.14，但须推送到仓库后才能获得远端执行结果。UDP、网页、心跳超时、自动重连、重试去重和持久化未实现，不在本次通过范围内。
